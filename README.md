# miniProject-DIO



Projeto para o curso Bootcamp Brasdesco da DIO.

Estudo sobre o legado deixxado por Benjamin Graham (Considerado o pai do investimento em valor) fazendo uso de fontes da internet. Fazendo uso do NotebookLM como caderno temático para suporte de conhecimento ao desenvolver sistema de suporte a decisão financeira.

Definir como encontrar o "valor intrínseco" (se possível) de empresas para dar suporte a decisões de diversificação de investimentos. E dar suporte a máxima de "o investidor inteligente é um realista que compra dos pessimistas e vende para os otimistas".
